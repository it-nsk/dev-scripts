# Участие в разработке

## Подготовка

```bash
composer install
```

## Проверки

Перед изменением создайте отдельную ветку. Перед отправкой изменений выполните:

```bash
composer validate --strict
composer test
composer test-docker-e2e
```

PHPStan и PHP CS Fixer также запускаются в GitHub Actions.

## Добавление команды

1. Добавьте отдельный класс в `src`.
2. Зарегистрируйте одну команду в `src/Cli.php`.
3. Не добавляйте проектные настройки в пакет: общая логика должна работать
   с типовыми defaults, а уникальные значения остаются в проекте.
4. Обновите Makefile, README и E2E-сценарий.

Один модуль должен отвечать за один инструмент. Не добавляйте промежуточные
абстракции без повторного практического использования.
